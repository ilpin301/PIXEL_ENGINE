14. Important Design Philosophy
The engine should follow these principles:
- Embedded-first: Design around microcontroller limitations, not desktop assumptions.
- Portable: Core engine code must not depend on a specific MCU.
- Modular: Features should be independently configurable.
- Efficient: Optimize RAM, CPU, flash, and display bandwidth.
- Extensible: New hardware platforms and rendering backends should be easy to add.
- Developer-friendly: Creating a simple game should require minimal boilerplate.
- Scalable: Support both simple arcade games and more ambitious sandbox games.
- Honest: Never claim a feature is feasible on hardware without considering its actual resource requirements.
Avoid trying to recreate the entire Terraria game or its full engine. The goal is to create a reusable embedded 2D game engine capable of supporting games with similar fundamental mechanics at an appropriate scale.
